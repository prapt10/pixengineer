## Medium description (150 words)

**Pix Engineer** is an AI productivity SaaS I developed with AI-assisted engineering. It includes four core tools:

- **App Builder** — generate complete React/Next.js/HTML projects from natural-language prompts.
- **Design to Code** — convert screenshots and mockups into production-ready code.
- **Prompt Engineer** — craft and refine prompts for coding, writing, and automation.
- **Pix Chat** — a streaming AI chatbot with threaded history, web search, vision upload, and free/premium model routing.

The product features Supabase auth, Row-Level Security, credit-based billing via Razorpay, responsive PWA support, SEO structured data, and an admin dashboard. It demonstrates end-to-end SaaS delivery: UI/UX, backend security, payments, AI orchestration, and deployment.
